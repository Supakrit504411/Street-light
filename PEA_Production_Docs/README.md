# PEA Tracking System

Production-ready overview for GAS + Google Sheets + Vercel frontend.

## Stack
- Frontend: HTML/CSS/JavaScript
- Backend: Google Apps Script (Code.gs)
- Database: Google Sheets (WBS, LOG, CONFIG)
- Storage: Google Drive

## Core Features
- Job tracking
- Workflow status updates
- File uploads
- Audit logs
- Role-based access

## Quick Start
1. Deploy GAS Web App
2. Configure public/config.js
3. Deploy frontend to Vercel
4. Verify bootstrap API
